Create `src-tauri/src/commands/hardware.rs` and implement these exact public snapshot structs with `#[serde(rename_all = "camelCase")]`:
- `CpuSnapshot`
- `GpuSnapshot`
- `MemorySnapshot`
- `DisplaySnapshot`
- `HardwareSnapshot`

Implement an async Tauri command with this exact signature:

```rust
#[tauri::command]
pub async fn get_hardware_snapshot() -> Result<HardwareSnapshot, AppError>
```

Implement CPU and memory detection using `sysinfo::System`:
- Instantiate with `System::new_all()`
- CPU model = first CPU `brand()`
- physical core count = `System::physical_core_count()`
- logical thread count = `system.cpus().len()`
- total memory bytes = `system.total_memory()`

Implement GPU detection with a typed WMI query against this exact class and field set:

```sql
SELECT Name, AdapterCompatibility, AdapterRAM, CurrentHorizontalResolution, CurrentVerticalResolution, CurrentRefreshRate
FROM Win32_VideoController
```

Deserialize the query into a Rust struct using `#[serde(rename_all = "PascalCase")]`. Normalize to one `GpuSnapshot` by selecting the first row with a non-empty `Name`; if multiple rows are available, prefer a row that has both `Name` and `AdapterRAM`.

Implement active display detection with Win32 APIs through the `windows` crate:
- Enumerate adapters with `EnumDisplayDevicesW(NULL, iDevNum, ...)`
- Ignore adapters that are not attached to the desktop
- For the first attached adapter, call `EnumDisplayDevicesW(adapter.DeviceName, 0, ...)` to get the monitor name
- Call `EnumDisplaySettingsW(adapter.DeviceName, ENUM_CURRENT_SETTINGS, ...)` and map `dmPelsWidth`, `dmPelsHeight`, and `dmDisplayFrequency` into `DisplaySnapshot`

Normalization rules:
- Never fabricate values such as `0`, `"Unknown"`, or guessed refresh rates in the Rust payload
- Return `None` / `null` for anything unavailable
- Keep the command best-effort: a failed GPU or display probe must not fail the full snapshot; only return `AppError` for command-level failures that prevent creating any snapshot at all
- Leave manual override out of Rust for this phase; the payload must represent detected values only
  </action>
