# Historical GSD Planning Archive

This directory is retained as historical migration context from OptiHub's previous Get Shit Done planning workflow.

## Status

- `.planning/` is no longer the default place for new requirement or workflow changes.
- New planning work should use the OpenSpec workflow under [`../openspec/`](../openspec/).
- Existing references inside this directory to `/gsd-*` commands are archival and should not be treated as the active default workflow.

## What stays here

- Product and roadmap snapshots used during the migration to OpenSpec
- Historical phase plans, summaries, research, validation, and UAT notes
- Legacy execution evidence that still helps explain completed work

## What to use instead

- [`../openspec/README.md`](../openspec/README.md) for the active planning workflow
- `../openspec/changes/` for new proposals and implementation checklists
- `../openspec/specs/` for the active capability baseline after archival
- [`../docs/repository-structure.md`](../docs/repository-structure.md) for the repository map and active-versus-historical boundaries
